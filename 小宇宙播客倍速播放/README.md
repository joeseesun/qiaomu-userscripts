# 小宇宙播客倍速播放

为小宇宙网页版单集页面增加固定的播放倍速控制面板，方便快速切换音频播放速度。

## 脚本文件

- `小宇宙播客倍速播放.js`

## 适用页面

- `https://www.xiaoyuzhoufm.com/episode/*`

## 主要功能

- 等待页面中的 `audio` 元素加载。
- 在页面右上角添加“播放倍速”控制面板。
- 支持 `0.5x`、`0.75x`、`1.0x`、`1.25x`、`1.5x`、`1.75x`、`2.0x`。
- 使用数字键 `1` 到 `7` 快速切换对应倍速。
- 当前倍速按钮会高亮显示。

点击 Raw 链接后，Tampermonkey 会打开安装页：

## 使用方法

1. 打开小宇宙网页版单集页面。
2. 等待音频播放器加载完成。
3. 点击右侧倍速按钮，或按数字键 `1` 到 `7` 切换倍速。

## 注意事项

- 脚本只匹配单集详情页，不匹配首页、节目页或搜索页。
- 如果页面长时间没有出现倍速面板，刷新页面并确认音频播放器已加载。
- 当前脚本不保存上次选择的倍速，刷新页面后默认回到 `1.0x`。
